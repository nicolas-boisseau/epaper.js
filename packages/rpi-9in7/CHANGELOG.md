All notable changes to this project will be documented in this file.

## 1.0.0 (2026-01-26)

### Features

* Initial release with support for Waveshare 9.7" IT8951 e-Paper display
* Support for 16 grayscale levels (4-bit)
* Support for 4 grayscale levels (2-bit)
* Support for black and white (1-bit)
* Horizontal and vertical orientation support
* Configurable VCOM value
